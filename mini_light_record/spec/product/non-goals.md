# 明确不做（Non-goals）

以下能力**当前不在产品范围内**。若需求方提出，应先改本文件与 roadmap，再排期实现，避免「默认会做」。

## 数据采集与对账

| 不做 | 原因 |
|------|------|
| 静默抓取微信 / 支付宝账单 | 无合规接口；违反隐私与平台规范 |
| 自动导入银行短信 / 邮件账单 | 复杂度高，非轻量产品定位 |
| 与第三方理财 App 双向同步 | 超出一期边界 |

## 客户端形态

| 不做（现阶段） | 说明 |
|----------------|------|
| 独立 iOS / Android App | 当前仅微信小程序原生；uni-app 多端为**规划中**，见 roadmap |
| 桌面端 / Web 记账台 | 无计划 |
| 小程序内嵌 H5 完整后台 | 管理能力放在「我的」与二级页即可 |

## 社交与商业化（一期）

| 不做 | 说明 |
|------|------|
| 账本市场、模板商店 | Canvas 标为二期 |
| 好友动态 / 点赞评论 | 非记账核心 |
| 订阅会员、应用内购买 | 未设计计费模型 |
| 广告变现 | 不做 |

## 记账高级能力（一期不做）

| 不做 | 现状 |
|------|------|
| 语音记账、拍照识票 | 规划中 |
| 转账（账户间，不计入收支） | 模型无 `to_account_id`；UI 无转账 Tab |
| 多币种、汇率 | 金额仅分；账本无 currency 字段 |
| 周期账单、待办还款、分期 | 无表结构 |
| 分类预算与预算告警推送 | 仅账本×月总预算 |
| CSV / Excel 导出 | 无接口 |
| 回收站恢复已删流水 | 有 `deleted_at` 软删，无恢复 UI/API |
| 票据图云存储 | Canvas 提及；当前无上传与 OSS |

## 权限与组织

| 不做（一期） | 说明 |
|--------------|------|
| 「仅查看」角色、流水审批流 | 仅有 `owner` / `admin` / `member` |
| 企业报销 / 多组织账套 | 不做 |
| 跨账本合并统计 | 统计均按单个 `book_id` |

## 品牌与合规

| 不做 | 说明 |
|------|------|
| 使用「随手记」等品牌名、Logo、文案 | 产品名固定为「轻记」 |
| 声称「官方同步」任何支付平台 | 禁止 |

## 运维与基础设施偏好

| 不做（偏好） | 说明 |
|--------------|------|
| 强制购买云数据库（RDS） | 默认本机 SQLite；可同机装 Postgres/MySQL |
| 多区域高可用集群 | 单机部署即可 |

> 若未来要做上表某项：先更新 `features.md` 状态、补 `api.md` / `data-model.md`，再改代码。
