# 信息架构与 UI 规范

## 底部五 Tab

与 `miniprogram/app.json` → `tabBar.list` 一致：

| 顺序 | 文案 | 路径 | 职责 |
|------|------|------|------|
| 1 | 首页 | `pages/home/home` | 月支出大字、收入、预算进度、最近流水、快捷入口 |
| 2 | 流水 | `pages/ledger/ledger` | 当月按日分组列表 |
| 3 | 记一笔 | `pages/record/record` | 记账主路径（中间突出） |
| 4 | 图表 | `pages/charts/charts` | 分类占比条 |
| 5 | 我的 | `pages/mine/mine` | 登录资料、账本、预算 |

Tab 色：未选 `#999999`，选中与导航栏 `#FF7A45`，背景白。

## 二级 / 非 Tab 页面

| 路径 | 入口 | 用途 |
|------|------|------|
| `pages/books/books` | 我的 → 账本管理 | 账本列表、筛选、创建、切换、进家庭 |
| `pages/family/family` | 账本管理 → 家庭 | 成员、分享/手机号邀请、移除 |
| `pages/invite/accept` | 分享 path / 冷启动 code | 预览并接受邀请 |

`app.json` 的 `pages` 数组顺序决定首页为 `home`。

## 与 Canvas 设计稿的差异（重要）

早期 Canvas「页面与路由表」使用如 `pages/home/index`、`pages/record/edit` 等路径；**实现以 `app.json` 为准**。下列 Canvas 能力尚未做成独立页：

| Canvas 设想 | 当前实现 |
|-------------|----------|
| 账户列表/编辑页 | 无；记一笔 ActionSheet |
| 分类管理页 | 无；记一笔拉树并两级选择 |
| 流水详情 / 筛选面板 | 无 |
| 预算独立编辑页 | 我的页 Modal |
| 转账 Tab | 无 |
| 饼图 + 趋势 | 占比条列表 |

## 视觉与交互规范

| 项 | 规范 |
|----|------|
| 主题色 | `#FF7A45` |
| 页面底 | `#F7F8FA` |
| 卡片 | 白底圆角；全局 class 见 `app.wxss` |
| 支出金额 | 红色系 `#E85D4C`（`amount-expense`） |
| 收入金额 | 绿色系 `#2FBF6B`（`amount-income`） |
| 金额展示 | 前端 `formatYuan(cents)` → 两位小数字符串；接口一律 `*_cents` |
| 导航栏 | 橙底白字，标题「轻记」 |
| 反馈 | 成功/失败多用 `wx.showToast`；记一笔成功可 `vibrateShort`；命名/预算用 `wx.showModal` |
| 空态 | 简洁图标 + 主文案 + 可选副文案；加载中用「加载中…」避免闪白 |
| 过渡 | 全局短过渡约 150–250ms（opacity / transform）；忌过重阴影动画 |
| 触控 | 可点区域用 `hover-class` / `:active`；分段、宫格、列表、菜单均有按压反馈 |
| 下拉刷新 | 首页、流水页 `enablePullDownRefresh` |
| 记一笔 | 大类→小类；未选小类/金额无效时「完成」呈禁用灰态；切支出/收入时分类区淡入淡出 |

## 全局状态（客户端）

| Key | 位置 | 含义 |
|-----|------|------|
| `token` | storage + globalData | JWT |
| `user` | storage + globalData | 当前用户对象 |
| `bookId` / `bookName` | storage + globalData | 当前工作账本 |
| `pendingInviteCode` | globalData | 启动时待跳转的邀请码 |

无 Redux/MobX；页面 `onShow` 普遍调用 `getApp().ensureLogin()`。

## 记一笔键盘（已实现行为）

- 数字 `0-9`、`.`、`00`、删除、清空
- 整数部分最长约 8 位；小数最多 2 位
- **无** `+ − =` 连续运算（Canvas 设想；属规划中）

## 无障碍与合规（规划中）

- 「我的」页脚仅文案「轻记 · 简洁好用的记账」
- 隐私政策 / 用户协议入口：**规划中**
