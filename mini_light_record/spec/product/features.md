# 功能清单

按模块列出能力。每项含：**描述**、**用户效果**、**主要规则**、**当前状态**（已实现 | 部分 | 规划中）。

状态判定以仓库代码为准（`backend/app/api/*`、`miniprogram/pages/*`）。

---

## 1. 登录与会话

### 1.1 微信登录换 JWT

| 项 | 内容 |
|----|------|
| 描述 | 小程序 `wx.login` 取 `code`，`POST /api/auth/login`；后端 `code2session` 得 `openid`，签发 JWT |
| 用户效果 | 打开小程序即可进入；开发环境可用 `MOCK_OPENID` 跳过真实微信 |
| 主要规则 | 新 openid → 建用户 + 种子数据；老用户更新 `last_login_at`；可选附带 `nickname` / `avatar_url` |
| 状态 | **已实现** |

### 1.2 Token 持久化

| 项 | 内容 |
|----|------|
| 描述 | JWT 存 `wx.storage`（`token`）与 `App.globalData`；请求头 `Authorization: Bearer …` |
| 用户效果 | 冷启动免重复登录（token 未过期时） |
| 主要规则 | 401 清除本地 token；默认过期 30 天（`JWT_EXPIRE_DAYS`） |
| 状态 | **已实现** |

### 1.3 正式微信 code2session

| 项 | 内容 |
|----|------|
| 描述 | 配置真实 `WX_APPID` / `WX_SECRET`，清空 `MOCK_OPENID` |
| 用户效果 | 真机正式版按微信用户区分账号 |
| 主要规则 | 未配置且无 MOCK 时登录返回 400 |
| 状态 | **部分**（代码路径已有；依赖运维配置与合法域名） |

## 2. 个人资料

### 2.1 查看 / 修改昵称与头像

| 项 | 内容 |
|----|------|
| 描述 | `GET/PATCH /api/me`；小程序「我的」用 `chooseAvatar` + `type=nickname` 输入框 |
| 用户效果 | 自定义展示名与头像，不必等于微信昵称 |
| 主要规则 | 昵称非空、最长 64；头像 URL 最长 512；头像目前多为本地临时路径，**未做服务端上传** |
| 状态 | **部分**（改昵称完整；头像依赖 URL，无对象存储上传） |

### 2.2 绑定手机号

| 项 | 内容 |
|----|------|
| 描述 | `POST /api/auth/phone`（微信 `getPhoneNumber` 的 code）；或 `POST /api/me/phone`（`phone_code` 或开发明文 `phone`） |
| 用户效果 | 家庭手机号邀请前可绑定；「我的」展示手机号 |
| 主要规则 | 规范化大陆 11 位；全局唯一；MOCK 下任意 code → `MOCK_PHONE` |
| 状态 | **已实现** |

## 3. 账本

### 3.1 个人账本

| 项 | 内容 |
|----|------|
| 描述 | `kind=personal`；创建者写入 `book_members.role=owner` |
| 用户效果 | 默认「日常账本」；可再建个人账本 |
| 主要规则 | 列表仅返回当前用户作为成员的账本；个人账本**不可邀请** |
| 状态 | **已实现** |

### 3.2 家庭账本

| 项 | 内容 |
|----|------|
| 描述 | `kind=family`；多人共享流水与统计 |
| 用户效果 | 「账本管理」可创建家庭；进入家庭详情管成员与邀请 |
| 主要规则 | 角色 `owner` / `admin` / `member`；记流水、读流水、统计均校验成员身份 |
| 状态 | **已实现** |

### 3.3 切换当前账本

| 项 | 内容 |
|----|------|
| 描述 | 本地 `bookId` / `bookName` 存 storage；首页/流水/记一笔/图表均读 `globalData.bookId` |
| 用户效果 | 「我的 → 快速切换」或「账本管理」点选后切换 |
| 主要规则 | 无服务端「当前账本」字段，纯客户端状态 |
| 状态 | **已实现** |

### 3.4 账本编辑 / 归档 / 删除

| 项 | 内容 |
|----|------|
| 描述 | 改名、归档、删除账本 |
| 状态 | **规划中**（仅有创建与查询；模型无 `archived`） |

## 4. 家庭邀请与成员

### 4.1 微信分享邀请

| 项 | 内容 |
|----|------|
| 描述 | `POST /api/books/{id}/invites` `{channel:"share"}` → 8 位码 + path `pages/invite/accept?code=…` |
| 用户效果 | 家庭页生成口令、复制；`onShareAppMessage` 可带 path；对方打开接受页加入 |
| 主要规则 | 仅 family；仅 owner/admin；默认 7 天过期；状态 `pending→accepted` / 超时 `expired` |
| 状态 | **已实现** |

### 4.2 手机号邀请

| 项 | 内容 |
|----|------|
| 描述 | `{channel:"phone", phone}`；接受时校验用户已绑定且号码一致 |
| 用户效果 | 定向邀请；接受页可先绑定手机号 |
| 主要规则 | 号码规范化；不匹配 → 403 |
| 状态 | **已实现** |

### 4.3 邀请预览（可匿名）

| 项 | 内容 |
|----|------|
| 描述 | `GET /api/invites/{code}` 无需登录 |
| 用户效果 | 接受页展示账本名、邀请人昵称、状态 |
| 状态 | **已实现** |

### 4.4 成员列表与移除

| 项 | 内容 |
|----|------|
| 描述 | `GET …/members`；`DELETE …/members/{user_id}` |
| 用户效果 | 家庭页展示成员；owner/admin 可移除 |
| 主要规则 | 不可移除 owner；admin 不可移除其他 admin |
| 状态 | **已实现** |

### 4.5 撤销邀请 / 升降级角色

| 项 | 内容 |
|----|------|
| 描述 | `revoked` 状态已在模型注释中；无专用撤销 API；无改角色 API |
| 状态 | **规划中** |

| 主要规则 | 最多两级；父子 type 一致；同级名唯一；**流水只能挂二级** |
| 状态 | **已实现**（管理 UI 仍为规划中） |

## 7. 记一笔（流水写入）

### 7.1 支出 / 收入

| 项 | 内容 |
|----|------|
| 描述 | `POST /api/records`；小程序 `pages/record`：类型切换、**先选大类再选小类**、简化数字键盘、备注、选账户 |
