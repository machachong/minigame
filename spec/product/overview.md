# 产品概述

## 产品名

**轻记** — 微信小程序内的轻量记账工具。对标「随手记」类产品的信息架构与交互习惯，但**不使用**对标品牌的名称、Logo 与官方文案。

## 一句话定位

打开微信就能记一笔：个人与家庭共用账本，流水按日回看，月底看收支与预算，不堆社交与市场功能。

## 目标用户

| 画像 | 诉求 |
|------|------|
| 个人微信用户 | 少装 App，聊天场景里快速记支出/收入 |
| 小家庭（2～5 人） | 共用一个家庭账本，互相看到谁记了什么 |
| 自建服务偏好者 | 数据落在自己的阿里云单机，不买云数据库 |

## 核心价值

1. **记一笔**：选收支类型 → 选一级大类 → 选二级小类 → 输入金额保存。
2. **流水按日分组**：本月支出红 / 收入绿，家庭账本可显示记账人昵称。
3. **月看板**：首页展示本月支出、收入、预算占用比例。
4. **家庭协作**：家庭账本 + 微信分享口令 / 手机号定向邀请。
5. **资料可控**：昵称可自定义（不必等于微信昵称），可绑定手机号。

## 成功标准（一期）

| 指标 | 说明 |
|------|------|
| 首笔时延 | 新用户冷启动后约 30 秒内能完成首笔记账（含自动种子账本/分类/账户） |
| 自助复盘 | 月活用户能在「流水」「图表」页看清本月分类占比，无需客服 |
| 家庭闭环 | 邀请人生成分享码，被邀请人打开小程序 path 后能加入并记账 |

## 技术选型（产品视角）

| 层 | 选型 | 说明 |
|----|------|------|
| 前端 | 微信原生小程序（WXML/WXSS/JS） | **不是** uni-app；代码在 `miniprogram/` |
| 后端 | Python FastAPI + SQLAlchemy + JWT | 代码在 `backend/` |
| 数据库 | 默认 SQLite；可换本机 PostgreSQL/MySQL | 不强制云数据库 |
| 登录 | 微信 `wx.login` → 后端 `code2session`（openid） | 开发可用 `MOCK_OPENID` |

## 产品范围边界（摘要）

**在范围内（一期已做或正在做）**

- 个人账本 / 家庭账本、成员角色、邀请
- 支出与收入记账、账户余额回写、软删除流水（API）
- 月汇总、分类占比（条形）、账本×月总预算
- 微信登录、昵称头像、手机号绑定

**明确不在范围内** → 见 [non-goals.md](./non-goals.md)

**愿景中但未落地** → 见 [features.md](./features.md) 中「规划中」与 [roadmap.md](../engineering/roadmap.md)
