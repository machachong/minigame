# 《敲到成佛》测试方案

> 版本:V1.0 | 2026-08-08 | 配套:`prd.md`(两期需求)、`tech-design.md`(技术方案)
> 适用范围:两期所有功能,按里程碑分阶段执行;个人开发者可用本方案做自测 + 内测验收。

---

## 一、测试策略总览

### 1.1 测试金字塔

```
          ┌─────────────┐
          │  审核自查     │  ← 上线前最后一道
          │  (合规专项)   │
          ├─────────────┤
          │  验收测试     │  ← 按里程碑 checklist
          │  (里程碑门禁)  │
          ├─────────────┤
          │  系统测试     │  ← 完整流程 + 异常场景
          │  (每里程碑末)  │
          ├─────────────┤
          │  模块测试     │  ← 各模块独立
          │  (开发中并行)  │
          ├─────────────┤
          │  手感专项     │  ← 敲击/音效/反馈(持续)
          │  (M2 起)      │
          └─────────────┘
```

### 1.2 测试阶段

| 阶段 | 时机 | 负责人 | 内容 |
|---|---|---|---|
| **开发自测** | 每个模块完成后 | 开发者 | 基础功能、边界条件、日志检查 |
| **手感调参** | M2~M3 持续迭代 | 开发者+内测 | 敲击节奏、音效反馈、飘字视觉 |
| **里程碑门禁** | 每里程碑 100% 时 | 开发者 | 对照本方案 checklist 逐项验收 |
| **内测体验** | M6~M7(完整一期) | 开发者+3~5 位好友 | 真实玩家行为观察、留存钩子验证 |
| **上线前审核自查** | M7 提审前 | 开发者 | 合规红线、性能、审核常驻项 |
| **线上监控** | 上线后持续 | 开发者 | 崩溃率、留存、eCPM 数据异常 |

### 1.3 个人开发者测试原则

1. **自测即主力**:没有独立 QA,代码写完必须自测通过再进里程碑门禁
2. **真机必测**:开发者工具和真机是两个世界(Canvas 渲染、音频、震动、安全区)
3. **弱网是常态**:所有网络相关功能必须在飞行模式/弱网下测一遍
4. **存档是命根**:杀进程、清缓存、换手机三个场景必过
5. **手感量化**:不凭感觉,用录音 + 连敲节奏记录做对比

## 二、测试环境矩阵

### 2.1 真机覆盖(最低要求)

| 平台 | 机型要求 | 微信版本 | 用途 |
|---|---|---|---|
| iOS | iPhone 12 或更新(主力) | 最新正式版 | 主力测试 |
| iOS | iPhone 8 / SE2 等老机型 | 最新正式版 | 低端兼容(80ms 防抖调参) |
| Android | 中端机型(如小米/OPPO 2000 元档) | 最新正式版 | 主力测试 |
| Android | 低端机型(如红米千元档) | 最新正式版 | 帧率/内存/包体极限验证 |

> 最少 3 台真机:iOS 1 台(iPhone 12+)、Android 1 台中端、1 台低端。不够的话找朋友借,远程调试也行。

### 2.2 网络环境

| 场景 | 测试方式 | 关键验证点 |
|---|---|---|
| 正常 WiFi | 日常开发环境 | 基准性能 |
| 4G/5G | 关闭 WiFi | 云函数响应、BGM 流式加载 |
| 弱网(2G 模拟) | 开发者工具 Network Throttle:Slow 3G | 超时降级游客模式(2.5s)、重连恢复 |
| 断网(飞行模式) | 物理开启飞行模式 | 本地可玩、数据缓存、重连后同步 |
| 网络切换 | WiFi ↔ 4G 来回切 | 同步任务不丢失、不重复上报 |

### 2.3 微信版本

- 最新正式版(主力)
- 前一个大版本(兼容验证,至少一次)
- 开发者工具 Stable(开发期)、RC(提审前验证)

## 十一、Bug 管理(个人开发者)

### 11.1 严重度定义

| 级别 | 定义 | 示例 |
|---|---|---|
| **S-阻塞** | 阻断测试/上线,无法继续 | 游戏闪退、存档丢失、白屏、审核必挂项 |
| **A-严重** | 核心功能不可用 | 敲击无反馈、功德不累加、境界不晋升、广告无奖励 |
| **B-一般** | 功能可用但有瑕疵 | 飘字延迟、皮肤切换有闪烁、UI 轻微错位 |
| **C-优化** | 不影响功能,体验可提升 | 文案建议、颜色微调、动画缓动曲线 |

### 11.2 处理流程

1. 发现 → 记录在 `mind_tap/spec/bugs.md`(或用 CloudBase 数据库 tracking)
2. **S/A 级**:立即修复,修复后必过回归测试
3. **B 级**:里程碑内修复,不做专项回归
4. **C 级**:攒到里程碑窗口期统一处理,延后至二期的不追

## 十二、内测与真实玩家观察

### 12.1 内测招募

- 时间:M6~M7
- 人数:3~5 位好友(覆盖目标用户:打工人/佛系青年/学生)
- 方式:开发者工具真机调试或体验版(绑定体验者)

### 12.2 观察要点

| 观察项 | 记录内容 |
|---|---|
| 首次敲击到持续敲击的转化 | 新手引导有没有触达?(几秒内开始敲,有没有困惑) |
| 连续敲击时长 | 自然停下来花了多长时间?平均敲多久? |
| 境界突破反应 | 晋升时用户有没有"哇"一下?有没有截屏分享? |
| 留存钩子是否触发 | 第二天有没有主动回来敲?为了每日功课还是离线收益? |
| 广告点击意愿 | 什么点位最愿意看视频?什么点位反感? |
