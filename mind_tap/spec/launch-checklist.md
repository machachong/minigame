# 《禅心木鱼》上线资质办理清单(软著 + 备案)

> 微信小游戏(无内购休闲类)**不需要版号**,提审必需两件:**软件著作权证书** + **备案号**。
> 原则:资质是日历时间,不是开发时间——**今天启动,与开发并行**。

---

## 一、先后顺序与并行关系

```
注册小程序账号(个人) → 软著申请(30~60 工作日,最慢,立即启动)
                        ↘ 拿到受理通知 → 提交备案(1~2 周) → 备案号
开发 M1~M7 并行 → → → → → → → → → → → → → → → → → 提审(软著+备案+代码包)
```

- 软著**拿到受理通知**即可提交备案,不必等证书(省 1~2 周)
- 备案须在提审前完成,且备案号出来后需回填小程序后台

---

## 二、软著(软件著作权)——最慢,今天启动

### 2.1 渠道
- 官方:中国版权保护中心 `www.ccopyright.com.cn`,全流程线上(个人可申请)
- 加急:官方无加急,代办机构最快 6~10 个工作日(几百~上千元,非必需)

### 2.2 材料(三件套)

| 材料 | 要求 | 注意事项 |
|---|---|---|
| 身份证 | 正反面扫描件 + 手持身份证半身照 | 实名认证用,约 1~3 个工作日通过 |
| 源代码 | 前 30 页 + 后 30 页,每页 ≥50 行,去空行;总代码不足 60 页则提交全部 | 页眉标注"软件名称 + 版本号";含前端核心逻辑,不要只给空壳 |
| 软件文档 | 操作手册/设计说明书,前 30 页 + 后 30 页 | 图文结合:主界面截图、功能模块图、境界/皮肤/离线等系统说明 |

### 2.3 填表要点(对应本项目)
- 软件全称:**敲到成佛微信小游戏软件 V1.0**(名称与游戏名关联,便于微信审核对应)
- 版本号:V1.0(与游戏版本一致)
- 开发方式:单独开发(个人)
- 开发完成日期:填实际编码完成时间(注意:2025 年起证书不再记载该日期,表中仍须如实填)
- 软件用途简述:禅意敲击 + 放置养成 + 疗愈小游戏,突出独创玩法(功德境界、皮肤音色、离线禅修)

### 2.4 费用与时间
- 官费:登记费已取消,普通登记基本免费(以官网为准,警惕收服务费的中介)
- 审查:30~60 工作日;收到补正通知须 30 日内回复,逾期视为撤回
- 取证:电子证书优先,官网可查验

---

## 三、备案(工信部小程序备案)——免费,1~2 周

### 3.1 入口
微信公众平台(mp.weixin.qq.com)→ 小程序后台 → 「设置」→「小程序备案」(或登录后的备案引导)

### 3.2 流程
1. 填写**主体信息**:个人主体填姓名、身份证号
2. 填写**负责人信息**:手机号、邮箱
3. 上传**身份证正反面**
4. **人脸识别核验**(微信内完成)
5. 选择服务内容:**小游戏 / 网络游戏**类目
6. 提交 → 省通信管理局审核(法定 20 个工作日内,通常 1~2 周)
7. 通过后获取**备案号**,回填小程序后台并按要求公示

### 3.3 前置
- 建议先有软著(或受理通知)再提交备案,避免被驳回
- 备案免费;个人主体可办,无需营业执照

| 事项 | 说明 |
|---|---|
| 名称查重 | 先在微信内搜索"敲到成佛",确认未被同名游戏占用(查重失败会被驳回) |
| 账号注册 | 微信公众平台注册"小游戏"类目账号,个人主体即可 |
| 内容审核 | 提审后 3~7 个工作日,驳回免费重提;注意名称合规、无未授权素材 |
| 流量主 | 累计 UV ≥ 1000 后开通激励视频广告(个人主体只能广告变现,无内购) |
