# 《敲到成佛》微信小游戏需求规格说明书

> 版本:V2.0(两期渐进式) | 2026-08-08
> 关联文档:`design.md`(设计方案)、`tech-design.md`(技术方案)、`launch-checklist.md`(上线资质)

## 一、产品概述

| 项 | 内容 |
|---|---|
| **游戏名称** | 敲到成佛 |
| **游戏类型** | 放置养成 / 节奏音乐 / 心灵疗愈 |
| **目标平台** | 微信小游戏(个人主体,广告变现) |
| **一句话定位** | 木鱼解压 + 佛系修仙:敲击解压、功德成长,从凡夫到成佛 |
| **核心体验** | 在敲击中感受宁静,在修行中体验成长——敲一下,功德+1,一路敲到成佛 |
| **目标用户** | 25~45 岁:高压打工人(解压)、佛系青年(情绪价值)、对"电子木鱼"梗有共鸣的传播人群 |
| **差异化亮点** | 把单调敲击升级为"敲击(解压)→ 功德(成长)→ 境界(修仙)→ 功法(深度)"的完整循环,融合节奏挑战、收集图鉴与情绪陪伴,既解压又上头 |

## 二、两期规划总览(渐进式开发)

**原则**:第一期用最小成本跑通"敲击—成长—回归"闭环,验证留存;第二期再上玩法深度与社交,做留存与 LTV。资质(软著/备案)自 M0 起与开发并行。

| 维度 | 第一期(核心闭环) | 第二期(完整玩法) |
|---|---|---|
| **目标** | 上线验证:手感、留存、广告收益 | 扩量:玩法深度、社交裂变、LTV |
| **核心验证** | 首日转化、3/7 日留存、广告 eCPM | 分享率、功法习得率、转生循环、LTV |
| **范围** | 敲击手感、功德境界、基础皮肤/场景/音频、离线禅修、每日功课、新手引导、存档云同步、功德榜、分享得功德、激励视频、埋点 | 功法节奏副本、涅槃转生、随机事件、皮肤场景深化、音色商店、共修/祈福/群、情绪木鱼、早课晚课、内购(企业主体后) |
| **周期** | 约 4~6 周(个人开发者) | 约 6~8 周 |
| **发布** | 首次提审上线 | 版本迭代上线 |

> 关键取舍:第一期的"每日功课 + 离线收益"是日留存双钩子,必须齐;功法、转生等深度内容一律后置,避免一期过重。

---

## 三、第一期需求(核心闭环)

优先级定义:P0 = 必须,缺了无法上线;P1 = 应有,影响体验/留存;P2 = 可后移。

### 3.1 敲击核心玩法【P0】

| 需求 | 说明 | 验收标准 |
|---|---|---|
| 敲击判定 | touchstart 计数,每帧至多结算 1 击;间隔 <80ms 的抖动合并 | 快速连敲手感流畅,无一次多点 |
| 视觉反馈 | 木鱼下压变形(scaleY 0.9,100ms 回弹)+ 功德飘字 + 光晕涟漪 | 每次敲击反馈完整无遗漏 |
| 听觉反馈 | 敲击音(WebAudio 合成,约 180Hz + 60ms 衰减),音色随皮肤切换 | 无爆音、切换即时 |
| 触觉反馈 | wx.vibrateShort 轻震,可开关;安卓可选强震 | 开关生效 |
| 连击系统 | 连击计数;10/50/100 档飘字文案("法喜充满"等)+ 专属音效;中断前 1.5s 渐隐光晕提示 | 连击节奏可感知,断连有提示 |
| 飘字规范 | 每次敲击必出,上浮 40px 渐隐 600ms | 高连击下不卡顿 |

### 3.2 功德与境界系统【P0】

- **功德产出**:单次功德 = 1 × (1 + 皮肤加成 + 功法加成);连击不直接加功德(防无脑狂敲、防刷)
- **境界线**(六阶,一期开放至"比丘"灰度,罗汉及以后按数据调整):

| 境界 | 累计功德 | 解锁内容 | 预期到达 |
|---|---|---|---|
| 凡夫 | 0 | 基础木鱼、默认场景 | 新手 |
| 居士 | 1,000 | 皮肤"檀木"、佛乐《心经》 | 约 1 天 |
| 比丘 | 10,000 | 皮肤"翡翠"、音色变化、《大悲咒》 | 约 1 周 |
| 罗汉 | 100,000 | 离线禅修、场景"竹林幽潭" | 4~6 周(灰度调参) |
| 菩萨 | 1,000,000 | 全部场景、称号飘字 | 3~4 个月 |
| 佛 | 10,000,000 | 终极特效、好友列表"成佛"状态 | 8~12 个月(靠转生加速) |

- **突破演出**:境界晋升播放专属动画 + 音效 + 金色飘字(新手留存关键奖励时刻)
- **目标指引**:境界页常驻"距下一境界还差 X 功德"

### 3.3 皮肤 / 场景 / 音频(基础版)【P1】

| 模块 | 一期范围 | 说明 |
|---|---|---|
| 木鱼皮肤 | 经典木色、檀木(+5%)、冰种翡翠(+10%) | 差异 = 换色板 + 换音色;特效后置 |
| 场景 | 青灯古佛(初始)、竹林幽潭(罗汉) | 代码绘制:底色 + 渐隐元素分层 |
| BGM | 《心经》《大悲咒》《金刚经》阶梯解锁 | 流式加载、切换淡入淡出;合规:用无版权/合成素材 |
| 白噪音 | 雨声、鸟鸣可叠加 | 音效池管理 |
| 美术风格 | **极简扁平禅意风**,全部 Canvas 矢量代码绘制 | 个人开发者零美术成本;位图单张 <200KB |

### 3.4 离线禅修(罗汉解锁)【P1】

- 公式:离线功德 = 等效 300 次/小时 × 境界系数,上限 12 小时(无加成 3,600/夜)
- 领取:看激励视频可翻倍(每日 1 次)
- 防作弊:以服务端 `lastSeenAt` 计算,客户端仅展示

### 3.5 每日功课与每日一偈【P1】(日留存双钩子)

- **每日功课**:每日敲满 100 下 → 领"精进宝箱"(随机功德/菩提子碎片),7 日全勤送限定挂饰
- **每日一偈**:每天首次敲满 100 下掉落禅语卡片(Canvas 生成,可转发)
- 实现:本地计数 + 日期戳,低开销

### 3.6 新手引导【P0】

- 首启 3 步引导:敲一下 → 看飘字/音效 → 打开境界页(总时长 <30s,可跳过)
- 首个里程碑(居士)做强演出
- 不强制,可跳过,不遮挡核心操作

### 3.7 存档与云同步【P0】

- 本地:wx.setStorage 全量镜像(秒开可用);云端为权威副本
- **弱网/首启容错**:云函数登录 2.5s 超时 → 游客模式本地可玩,后台静默重试,联网自动同步
- 合并:字段级合并(本地未同步增量 ∪ 云端)
- 防刷:功德批量上报,服务端按时间窗口与速率校验

### 3.8 社交与分享【P1】

| 需求 | 说明 |
|---|---|
| 好友功德榜 | 开放数据域渲染;每 30s 或结算后节流上传(频控) |
| 分享得功德 | 每日首次分享 → 双方各 +100 功德(强钩子,必须一期上) |
| 分享卡 | 昵称 + 境界徽章 + 偈语 + "来敲一下"按钮;5:4;支持带参拉新 |

### 3.9 商业化:激励视频(基础)【P1】

| 点位 | 内容 | 频控 |
|---|---|---|
| 随喜加成 | 今日功德翻倍 | 每日 3 次 |
| 离线翻倍 | 离线收益 ×2 | 每日 1 次 |
| 佛光延长 | 事件 +30s | 事件触发 1 次 |
| 功德钥匙 | 开副本钥匙(为二期预埋) | 每日 2 次 |
| 皮肤试用 | 限时体验限定皮肤 | 每日 1 次 |

- 首次进入 60s 内无广告;按钮文案用中性词("静心加成""禅茶一盏"),**禁用"随喜/供养/添灯油"等宗教献金暗示词**
- 每日广告 ≤6 次,超限置灰"明日再来"

### 3.10 埋点(基础)【P1】

- 事件:启动、敲击时长、境界突破、每日功课完成、广告点击/完播、分享成功
- 渠道:云开发统计;上线首周重点看首日转化、3 日留存、eCPM

### 3.11 第一期验收清单

- [ ] 敲击手感自测达标(连续敲击 2 分钟无卡顿)
- [ ] 数据流打通:敲击 → 功德 → 境界 → 存档 → 云同步
- [ ] 杀进程重进数据不丢;断网可玩,联网自动同步
- [ ] 每日功课/每日一偈/分享得功德三个钩子全部生效
- [ ] 排行榜实时刷新、分享卡可转发
- [ ] 激励视频完播计数与奖励发放一致
- [ ] 软著 + 备案已提交(并行进行中)

## 四、第二期需求(完整玩法)

### 4.1 功法与节奏副本【P0】

- 谱面 JSON 格式(见 design.md 3.1),音符:单点/长按/滑动;判定 Perfect ±50ms / Good ±120ms
- 五部经:心经 ★ → 华严经 ★★★★★;无谱面预览,光晕预警
- 评价:无上正觉(+20%)/ 明心见性 / 初窥门径 / 杂念纷飞(失败不耗钥匙)
- 功法:静心咒、慈悲愿、般若力、破魔印、法界观、大愿力(数值/概率/事件/挂机/社交型)
- 主动真言:六字大明咒、往生咒·净土莲华(能量槽)
- 功法槽:境界决定数量(1/2/3);功德升级 + 顿悟点词条(菩萨)

### 4.2 涅槃转生【P1】

- 功德 ≥100 万可入灭:功德清零,获舍利子;舍利子兑换永久加成(+功德/次)、隐藏皮肤/BGM
- **待定项(需拍板)**:转生后境界处理——建议"境界保留 + 功德从新累积",或"境界降一级但保留皮肤解锁",避免负反馈

### 4.3 随机事件【P1】

- 烦恼气泡(敲击消除,奖功德,配合"破魔印")、佛光普照(30s 翻倍)、菩提子(集 10 兑换限定装扮)

### 4.4 自定义深化【P1】

- 皮肤:赛博朋克(+15%,分享解锁)、大日金乌(+20%,限时);场景:敦煌壁画、雪山之巅;音色商店(水滴、钟磬等)

### 4.5 社交深化【P1】

- 共修莲灯(好友头像化灯,互相点亮得功德)、祈福传递(生成祝福链接)、群共修(群目标,全员达成领奖)

### 4.6 情绪木鱼与早课晚课【P2】

- 情绪木鱼:选情绪 → 敲击文字渐散 → 治愈文案
- 早课晚课:6-8 点 / 21-23 点敲满 100 下领"精进宝箱",7 日全勤限定挂饰

### 4.7 商业化深化【P2】

- 企业主体后可开内购:功德钥匙礼包、菩提子直购、禅修月卡(离线上限+专属音色+去广告)

## 五、两期数据指标

| 指标 | 第一期目标 | 第二期目标 |
|---|---|---|
| 首日转化(注册→首次敲击) | ≥70% | ≥70% |
| 3 日留存 | ≥25% | ≥35% |
| 7 日留存 | ≥12% | ≥20% |

## 六、上线资质与合规(摘要)

- **资质**:软著(30~60 工作日)+ 备案(1~2 周),M0 起与开发并行;无内购无需版号;流量主需 UV ≥1000
- **名称**:查重后定名《敲到成佛》;软著名称"敲到成佛微信小游戏软件 V1.0"与游戏名关联
- **合规**:经文用无版权/合成素材;文案避开"迷信/祈福必应/宗教献金"表述;昵称内容走 msgSecCheck;个人主体无虚拟支付
- 详见 `launch-checklist.md`
